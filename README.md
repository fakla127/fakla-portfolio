# fakla — персональное портфолио

Личный сайт начинающего разработчика Артёма Бертенева (fakla).
Он рассказывает об обучении, технологиях и способах связи с разработчиком.
Коммерческий опыт, отзывы, заказы и вымышленные проекты не добавлены.

## Технологии и файлы

HTML5, CSS3 и обычный JavaScript. Сборка, npm, библиотеки, внешние шрифты
и серверная логика не нужны.

| Файл | Назначение |
| --- | --- |
| `index.html` | Семантическая структура, секции, контакты и русский запасной текст без JS. |
| `css/style.css` | Базовое оформление, типографика, компоненты и переменные двух тем. |
| `css/media.css` | Все адаптивные правила, ориентации и уменьшение движения. Подключается последним из CSS. |
| `js/translations.js` | Полные переводы RU / EN и настройка английского имени. |
| `js/main.js` | Язык, тема, сохранение настроек и мобильное меню. |
| `assets/favicon.svg` | Значок вкладки. |
| `assets/telegram.svg`, `assets/github.svg`, `assets/mail.svg` | Иконки контактов. |
| `assets/sun.svg`, `assets/moon.svg` | Иконки переключения темы. |
| `.nojekyll` | Пустой технический файл для публикации обычных статических файлов без Jekyll. |
| `README.md` | Эта инструкция. |

## Как открыть локально

Можно открыть `index.html` двойным щелчком. Установка зависимостей не нужна.
Для разработки и проверки сохранения настроек удобнее локальный HTTP-сервер:

1. Откройте эту папку в VS Code.
2. Если используете расширение Live Server, выберите **Open with Live Server**
   у `index.html`.

Другой способ, если Python уже установлен: откройте терминал в папке проекта
и выполните:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Перейдите на <http://127.0.0.1:8000/>. Для остановки нажмите Ctrl+C.
Python нужен только для такого предпросмотра; самому сайту он не требуется.

## Как менять тексты и переводы

Основные тексты находятся в обычном объекте `translations` в
`js/translations.js`. У русского и английского языков одинаковые ключи.
Например, `heroDescription` — описание на первом экране.

В `index.html` найдите соответствующий атрибут:

```html
<p class="hero-description" data-i18n="heroDescription">Русский запасной текст.</p>
```

Меняйте текст в `ru` и `en`. Русский текст внутри HTML тоже обновляйте:
он отображается, если JavaScript отключён. Для доступных названий и подсказок
используются `data-i18n-aria-label` и `data-i18n-title`, для метаописания —
`data-i18n-content`. Заголовок вкладки переводится через `pageTitle`.

Английское имя меняется в одном месте в начале `translations.js`:

```js
const portfolioConfig = {
  englishName: "Artyom Bertenev"
};
```

Ник `fakla`, адреса и названия технологий не переводятся. Ник всегда строчный.
Год подвала задан в `footerCopyright` обоих языков и в запасном тексте HTML.

## Как менять цвета

Откройте начало `css/style.css`. В `:root` находятся переменные тёмной темы,
в `[data-theme="light"]` — отличающиеся значения светлой.

Например, `--color-background` задаёт фон, `--color-text` — основной текст,
`--color-muted` — второстепенный текст, `--color-accent` — фон основной кнопки.
Меняйте переменные, затем проверяйте обе темы. У светлой темы свой цвет
акцентного текста: фиолетовый фон кнопки и фиолетовый мелкий текст имеют разные
задачи и требуют разной контрастности.

Все изменения для размеров экранов размещайте в `css/media.css`.
Не прячьте переполнение через `overflow-x: hidden`: исправляйте ширины и сетку.

## Как добавить раздел

1. Добавьте в `<main>` новый `<section>` с уникальным `id`, классом `section`
   и заголовком `<h2>`. Свяжите секцию с заголовком через `aria-labelledby`.
2. Используйте существующий `.container`, чтобы сохранить общую ширину.
3. Добавьте ссылку `href="#id-раздела"` в `.navigation`.
4. Для новых текстов создайте ключи в обоих языках и укажите `data-i18n`.
5. Базовые стили добавьте в `style.css`, адаптивные — в `media.css`.
6. Проверьте телефон, планшет и компьютер в двух языках и темах.

Дополнительный JS для обычной якорной ссылки не нужен. При выборе нового
пункта мобильное меню также закроется автоматически. Проекты стоит добавлять
только после появления реальных работ.

## Как работает интерфейс

- `setLanguage()` переводит текст и атрибуты, меняет `lang` и состояние RU / EN.
- `setTheme()` меняет `data-theme`, иконку, подпись кнопки и `theme-color`.
- `readPreference()` и `savePreference()` безопасно обращаются к `localStorage`.
- `setMenuOpen()` управляет раскрытием меню и `aria-expanded`.
- `setupEventListeners()` один раз подключает события.
- `initializeSite()` восстанавливает настройки и включает кнопки.

По умолчанию язык русский. При первом посещении тема соответствует
`prefers-color-scheme`; после ручного выбора используется сохранённая тема.
Ключи: `fakla-language` и `fakla-theme`. Если браузер запрещает хранилище,
переключение продолжает работать, но выбор не переживает перезагрузку.
Разные адреса и порты, а также `file://` и HTTP не делят настройки между собой.

Меню доступно до 767 px. Оно закрывается кнопкой, по Escape и при переходе
к разделу. При открытии клавишами Enter или Space фокус переходит к первой
ссылке; Escape возвращает его на кнопку. Прокрутка страницы не блокируется.
Без JavaScript навигация остаётся видимой, переключатели отключены.

Плавную прокрутку выполняет браузер. `scroll-padding-top` оставляет место для
шапки. При `prefers-reduced-motion: reduce` прокрутка обычная, переходы отключены.

## Как опубликовать на GitHub Pages

Публикацию пользователь выполняет самостоятельно:

1. Создайте в своём аккаунте обычный публичный репозиторий `fakla-portfolio`.
2. Поместите файлы проекта в его корень, сохранив папки `css`, `js` и `assets`.
   Рядом должны находиться `index.html` и `.nojekyll`.
3. Сохраните файлы в ветке `main`.
4. В репозитории откройте **Settings → Pages**.
5. В **Build and deployment → Source** выберите **Deploy from a branch**.
6. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
7. Дождитесь успешной публикации и откройте адрес, показанный GitHub.

Для аккаунта `fakla127` и такого имени репозитория ожидаемый адрес после
публикации: <https://fakla127.github.io/fakla-portfolio/>.
При другом имени репозитория изменится последняя часть адреса.
Все пути к CSS, JS, иконкам и якорям относительные; менять их для подпапки не нужно.
Отдельная установка Jekyll, Node.js или настройка сборки не требуется.

Инструкция сверена с [официальной документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
Назначение `.nojekyll` описано в [инструкции создания сайта](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

После публикации проверьте сайт по настоящему адресу, включая обновление страницы,
язык, тему и контакты. В портфолио Freelance.ru можно добавить ссылку на сайт
и его реальные скриншоты, описав работу как разработку личного портфолио.
Опыт клиентов и заказов при этом не подразумевается.
